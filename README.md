# Умный персональный ассистент

Веб-приложение для управления задачами с аналитикой выполнения, созданное на Flutter.

##  Основные возможности

- **Управление задачами** - создание, редактирование, удаление задач
- **Система приоритетов** - высокий, средний, низкий приоритет с цветовой индикацией
- **Дедлайны** - установка сроков выполнения задач
- **Аналитика** - статистика выполнения по приоритетам
- **Темная тема** - переключение между светлой и темной темой
- **Локальное хранение** - данные сохраняются в браузере

## 🛠 Технологии

- **Flutter** - фреймворк для кроссплатформенной разработки
- **Riverpod** - управление состоянием приложения
- **Shared Preferences** - локальное хранение данных в браузере
- **Intl** - форматирование дат

##  Установка и запуск

### Предварительные требования
- Flutter SDK (версия 3.0+)
- Chrome браузер для тестирования

### Запуск проекта

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd personal_assistant
   ```

2. **Установка зависимостей**
   ```bash
   flutter pub get
   ```

3. **Запуск в веб-режиме**
   ```bash
   flutter run -d chrome
   ```

### Сборка для производства

```bash
flutter build web
```

Собранные файлы будут находиться в папке `build/web`.

##  Архитектура проекта

```
lib/
├── Модели данных
│   └── Todo - модель задачи
├── Сервисы хранения
│   └── WebStorageService - работа с localStorage через Shared Preferences
├── Репозитории
│   └── TodoRepository - управление задачами
├── Провайдеры
│   └── Riverpod провайдеры для состояния
└── Экранs
    ├── LoginScreen - вход в систему
    ├── HomeScreen - главный экран с вкладками
    ├── DashboardScreen - дашборд с прогрессом
    ├── TodoListScreen - список задач
    └── AnalyticsScreen - аналитика
```

##  Как использовать

### Добавление задачи
1. Нажмите кнопку "+" на экране задач
2. Заполните описание задачи
3. Выберите приоритет (высокий, средний, низкий)
4. Установите дедлайн (опционально)
5. Нажмите "Добавить"

### Управление задачами
- **Отметка выполнения** - чекбокс в карточке задачи
- **Удаление** - свайп карточки влево/вправо
- **Просмотр дедлайнов** - отображается в подзаголовке карточки

### Аналитика
- **Общая статистика** - количество выполненных и общих задач
- **Процент выполнения** - визуальный прогресс-бар
- **Статистика по приоритетам** - распределение выполненных задач

##  Особенности реализации

### Хранение данных
Приложение использует `shared_preferences` для хранения данных в localStorage браузера. Все задачи сохраняются между сессиями.

### State Management
Управление состоянием реализовано с помощью Riverpod, включая:
- `StateProvider` для темы и аутентификации
- `FutureProvider` для асинхронных операций
- `Provider` для вычисляемых значений

### Адаптивный дизайн
Интерфейс адаптирован для различных размеров экранов и поддерживает жестовое управление.
