# Умный персональный ассистент

Flutter-приложение для управления задачами с аналитикой и системой приоритетов.

##  Функциональность

###  Аутентификация
- Простая форма входа для защиты доступа
- Возможность выхода из системы

### Темы
- Поддержка светлой и темной темы
- Переключение между темами в реальном времени

###  Основные экраны
- **Дашборд** - обзор прогресса и ближайшие задачи
- **Список задач** - полное управление задачами
- **Аналитика** - статистика выполнения по приоритетам

###  Управление задачами
- Добавление новых задач с описанием
- Установка приоритетов (низкий, средний, высокий)
- Назначение дедлайнов
- Отметка выполнения задач
- Удаление задач свайпом
- Визуальные индикаторы приоритета

###  Аналитика
- Общая статистика выполнения
- Аналитика по приоритетам
- Процент выполнения задач

##  Технологии

- **Flutter** - фреймворк для кроссплатформенной разработки
- **Riverpod** - управление состоянием приложения
- **SQFlite** - локальная база данных
- **Intl** - форматирование дат и локализация

##  Установка и запуск

### Предварительные требования
- Flutter SDK (последняя стабильная версия)
- Android Studio / VS Code с Flutter расширением

### Шаги установки

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd personal_assistant
   ```

2. **Установка зависимостей**
   ```bash
   flutter pub get
   ```

3. **Запуск приложения**
   ```bash
   flutter run
   ```

### Сборка для производства

**Android:**
```bash
flutter build apk --release
```

**iOS:**
```bash
flutter build ios --release
```

##  Ключевые особенности

### State Management с Riverpod
- `StateProvider` для темы и аутентификации
- `FutureProvider` для асинхронных операций с БД
- `Provider` для вычисляемых значений

### Локальная база данных
- Автоматическое создание таблиц
- CRUD операции для задач
- Сохранение состояния между сессиями

### Пользовательский интерфейс
- Адаптивный дизайн
- Material Design компоненты
- Плавные анимации
- Интуитивная навигация

## 📊 Структура данных

### Модель задачи (Todo)
```dart
{
  id: Int?,
  description: String,
  isCompleted: Bool,
  createdAt: DateTime,
  deadline: DateTime?,
  priority: Priority,
  estimatedMinutes: Int?
}
```

### Приоритеты
-  Высокий (High)
-  Средний (Medium)
-  Низкий (Low)

##  Настройка и кастомизация

### Добавление новых полей задач
1. Обновите модель `Todo` в `todo.dart`
2. Добавьте поле в таблицу БД в `database_helper.dart`
3. Обновите методы `toMap()` и `fromMap()`
4. Добавьте поле в UI формы создания задач

### Изменение цветовой схемы
Отредактируйте темы в `PersonalAssistantApp`:
```dart
theme: ThemeData.light(),    // Светлая тема
darkTheme: ThemeData.dark(), // Темная тема
```
